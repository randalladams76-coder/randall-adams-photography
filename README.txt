RANDALL ADAMS PHOTOGRAPHY | PERENNIAL PORTRAITS
Clean editorial website starter

FILES
- index.html: homepage and page content
- style.css: responsive layout and styling
- script.js: mobile navigation and image lightbox
- images/: supplied photography assets

BEFORE PUBLISHING
1. In index.html, replace REPLACE-WITH-YOUR-EMAIL@example.com with the business email address you want clients to use.
2. The current set of provided photographs includes studio portraits and one behind-the-scenes wedding image. The Family Photography section is intentionally text-led until you add genuine family-session photographs; it does not mislabel portrait photos as family work.
3. Check the mobile and desktop layout and ensure you have permission to publish every photograph.

PUBLISHING WITH GITHUB PAGES
Upload index.html, style.css, script.js, README.txt and the entire images folder to the root of the public repository. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save. Wait for GitHub Pages to publish before configuring DNS. Keep the existing xneelo DNS records until the GitHub Pages custom-domain instructions tell you exactly what to change.
